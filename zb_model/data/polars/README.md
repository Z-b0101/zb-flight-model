# Polar data

## mh60.dat — TO BE ADDED

Source: UIUC airfoil database, via the AeroSandbox mirror
(`aerosandbox/geometry/airfoil/airfoil_database/mh60.dat` — coordinates
verified present in the traceability audit, row B3d).

The polar *numbers* (Clmax 1.16, Cm0) live on airfoiltools.com
(`xf-mh60-il-100000`, XFoil Ncrit 9, Re 100k, full table extracted for the
trade study). `scripts/regenerate_polars.py` regenerates the polar tables
from `mh60.dat` reproducibly once an XFoil binary is on PATH.

Do not commit polars generated by any other means without noting the
provenance in `assumptions.yaml`.
